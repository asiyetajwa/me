# BW Simiyu

A personal website about building at the intersection of data, capital and culture.

**Production:** https://asiyetajwa.github.io/me/

Plain HTML, CSS and JavaScript. No build step, tracking, API keys, dependencies or backend. Serve this directory using any static HTTP server. GitHub Pages should publish the repository root from `main`.

## Editing

- Content and metadata: `index.html`
- Styling and responsive layouts: `style.css`
- Keyboard-accessible theory tabs, local time and email copy: `script.js`
- Locally hosted typefaces: `fonts.css` and the font files
